Sales核心阶段
›
触发信号 · 顾问主动私信
  • 主动提交学生试卷/essay/写作样本
  • 明确说明当前成绩与目标成绩差距
  • 询问具体exam board相关问题
  • 参加完整直播并在直播中提问
  • 连续多次参与群内讨论
  • 询问教师背景或考官资质
  • 主动询问10/30/50小时课包区别
  • 提到即将到来的Mock/考试/转学节点
  • 表示学校教师无法解决具体问题
注意：部分高价值家长很少发言，但会阅读所有内容并提交材料，不应以群内活跃度判断购买意愿
一对一诊断 · 标准输出
  • 学生当前阶段 + 问题分类
  • 当前成绩与目标成绩的差距量化
  • 优先解决的1-2个核心问题
  • 预计学习周期（建议8-12周）
  • 推荐教师层级（£90 / £130）
  • 推荐课包（10 / 30 / 50小时）
  • 阶段评估节点设置
  • 家长和学生需要配合的具体事项
诊断输出必须是可理解的学习路径，不能只说"建议上课"
★ 破冰课包的正确定位：定位为"教师面试课"而非试听。话术：「第一节课您可以全程观察教师如何分析孩子的答题，如果方向对了，我们再讨论后续计划。」S类家长对这个定位接受度极高，且能自然引导至10小时课包。
★ 收费诊断设计（£19-49）：含试卷/essay/能力深度分析，由资深教师完成，购买课包后全额抵扣，每期限5名额。目的是筛选真实行动意愿而非筛选预算——能付£30诊断费的家长几乎一定会认真配合。免费试听不建议作为主要转化产品。

付费服务群标准配置
  • 成员：家长 + 课程顾问 + 教师（必要时加入学术负责人）
  • 明确课程目标 / 排课安排 / 阶段反馈 / 缺课规则
  • 顾问响应时间承诺（建议工作日4小时内）
  • 阶段复盘节点（建议每10课时一次）
  • 续费评估节点：课包剩余20%时顾问主动提起，不等家长询问
  • 教师更换规则提前说明（避免成为投诉触发点）
续费 + 跨科 + 转介绍路径
  • S类：冲刺完成 → 成绩复盘 → 下一科目 → A-Level / 大学申请
  • A类：KS3能力 → IGCSE Readiness → IGCSE学科 → S类冲刺
  • 转介绍触发时间：付费后第5节课结束时，顾问主动触达：「孩子上课状态很好，如果有朋友也在准备[科目]，可以安排优先评估...」
  • 转介绍激励：推荐成功后送£30课时抵扣券（对高客单价家长有意义但不显廉价）
  • 期满未成交家长唤醒：社群结束30天内，顾问根据CRM标签定向私信，推送下期活动或新相关内容
